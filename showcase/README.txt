星语穹庭 · 复赛作品演示页面
═══════════════════════════════════

【 打开方式 】
直接双击 index.html，或用任意本地静态服务器打开：
  - 方式一：资源管理器里直接双击 showcase/index.html
  - 方式二：在 showcase 目录运行：
       Python 3:    python -m http.server 8080
       Node:        npx serve -p 8080
       然后访问 http://localhost:8080

【 文件说明 】
  index.html   演示入口
  styles.css   样式（对齐主项目设计 token，深空金紫配色）
  scenes.js    8 幕场景定义（每一幕：标题/旁白/时长/渲染函数）
  player.js    自动播放引擎（打字机字幕、进度条、场景切换、背景粒子）

【 演示流程（8 幕，约 90 秒） 】
  1. 封面          → 星语穹庭品牌 Hero + 关键数字
  2. 真实星空       → 6142 颗恒星 · 行星 · 星座 · 天球 HUD
  3. 天镜览星       → 取景框 + HUD + 观星/听语模式 + 故事列
  4. 行星特写       → 火星观察模式 + 行星数据面板 + 轨迹线
  5. 古人陪看       → 23 位古人列表 + SSE 流式聊天窗口
  6. 穹庭书局       → 官方八卷轴 + 星笺书架 + AI 解读·卷目疏
  7. 个人穹庭       → 月亮 Hero · 时间轴 · 私人星座 · 典藏星展
  8. 心事归星       → 投递表单 · AI 三步进度 · Top3 候选星面板

【 操作方式 】
  自动播放        默认开启，约 90 秒播完一轮，循环
  Space           暂停 / 继续
  ← / →           上一幕 / 下一幕
  Esc             回到封面
  右侧小圆点       点击直接跳转到对应幕
  顶部按钮        上一幕 / 播放暂停 / 下一幕
