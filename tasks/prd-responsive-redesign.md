# PRD: 响应式重构 — PC/移动端自适应

## 1. 概述

当前 `feat/mobile-story-ui` 分支将搜索栏统一为底部抽屉式，导致 PC 端也使用移动端交互，体验不佳。同时 StarDetail 详情面板缺乏移动端响应式布局，在小屏设备上右栏固定 340px 导致左栏被挤压成一条线。

本 PRD 定义响应式重构方案：PC 端恢复内嵌搜索栏和双栏详情布局，移动端保留底部抽屉和单栏布局，实现真正的自适应体验。

## 2. 目标

- **PC 端搜索栏**：恢复导航栏内嵌搜索框（居中）+ 下拉结果面板
- **移动端搜索栏**：保留底部抽屉式搜索，不做改动
- **PC 端 StarDetail**：保持当前双栏布局（左故事 + 右信息 340px）
- **移动端 StarDetail**：底部抽屉式单栏布局，可拖拽，支持手势交互
- **断点统一**：768px 作为 PC/移动端分界点
- **零回归**：PC 端所有功能（搜索、共鸣、收藏、删除、标签编辑等）保持原有行为

## 5. 非目标（范围外）

- 不改动后端 API
- 不改动桌面端 UI 布局和交互（除搜索栏外）
- 不新增用户权限系统
- 不改动 3D 天空渲染逻辑
- 不实现新的故事投递表单设计
- 不添加触摸手势库（如 Hammer.js），使用原生 touch 事件

## 6. 设计考量

- **移动端优先设计语言**：参考 iOS 底部抽屉（Bottom Sheet）模式，两级高度 + 拖拽条
- **视觉一致性**：复用现有 Design Token 体系（`client/src/styles/variables.css`），确保颜色、圆角、间距统一
- **动效**：所有过渡动画使用 `cubic-bezier(0.32, 0.72, 0, 1)` 缓动，时长 0.2~0.4s
- **可访问性**：焦点管理、键盘导航（Escape 关闭）、ARIA 标签
- **组件复用**：StarHeader、StarInfoPanel、StoryList、StoryDetail、BottomBar 等子组件在 PC/移动端共享，仅布局编排不同

## 7. 技术考量

### 实现策略（混合）
- **搜索栏**：条件渲染（`v-if="!isMobile"`），PC/移动端共用模板结构
- **StarDetail**：`index.vue` 共享所有状态逻辑（computed、methods），模板使用 `v-if` 分叉渲染 PC/移动端布局
- **避免双份逻辑**：所有交互逻辑（共鸣、收藏、删除、标签编辑）只写一份，PC/移动端复用

### 关键依赖
- Vue 3 Composition API + `<script setup>`
- 现有 Design Token CSS 变量
- 原生 touch 事件（拖拽）
- `window.matchMedia`（响应式检测）
