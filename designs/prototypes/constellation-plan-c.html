DESIGN NOTES · 设计说明

两层意义的 经 / 纬 编织

三环轨道：节点分布的参考椭圆，营造天球感
时间主链（经）：01 → 02 → 03 → … → 闭合回 01，白金色渐变实线，代表心事记录的时间顺序
共星支线（纬）：两则心事挂在 同一颗恒星 就画一条紫色脉冲虚线，画得越密说明这颗星让你反复驻足

为什么是"纺织"？经（纵）线是时间，不能断；纬（横）线是你在某些星上的"回望"与"重访"。每多写一则共星的心事，就多织入一根纬线，星座图案就会越来越密、越来越像 真正的织物。

数量规则：时间主链永远有 N 条（N = 故事数），加 1 条闭合线（最后一颗回第一颗）。共星支线 0 ~ N-1 条，取决于你是否重访同一颗星。
